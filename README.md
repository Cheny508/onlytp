onlyTP 是一个轻量级的 Minecraft Forge 传送模组。

玩家可以通过聊天栏输入 /otp 命令，将自己快速传送到指定坐标。支持跨维度传送、浮点坐标以及维度自动补全，无需开启作弊权限即可使用。

功能特点
使用 /otp x y z 传送到当前维度指定坐标
使用 /otp x y z dimension 跨维度传送
支持整数和浮点坐标
支持维度 Tab 自动补全
无需开启作弊模式
轻量、简单、无额外方块或物品
示例

当前维度传送：

/otp 100 70 200

跨维度传送：

/otp 0 80 0 minecraft:the_nether

onlyTP is a lightweight teleportation mod for Minecraft Forge.

Players can use the /otp command in the chat to teleport to specific coordinates. The mod supports cross-dimension teleportation, floating-point coordinates, and automatic dimension tab completion without requiring cheats to be enabled.

Features
Teleport using /otp x y z in the current dimension
Cross-dimension teleport using /otp x y z dimension
Supports integer and decimal coordinates
Automatic dimension tab completion
Works without enabling cheats
Lightweight design with no additional blocks or items
Examples

Teleport in the current dimension:

/otp 100 70 200

Teleport to another dimension:

/otp 0 80 0 minecraft:the_nether
